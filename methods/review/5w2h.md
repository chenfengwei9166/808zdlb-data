# 5W2H分析法

> 适用：审材料（5种用途本质追问）、写材料（需求确认）

## 核心

7个问题，任何一个答不上来就说明材料还没想清楚。

| 问 | 检查什么 | 材料中常见的漏洞 |
|----|---------|----------------|
| Why | 为什么要做、要推动什么决策 | 材料讲了很多"做了什么"，不讲"要领导批什么" |
| What | 到底要说什么、核心信息是什么 | 信息堆砌，一句话说不清楚 |
| Who | 给谁看、谁负责、谁协同 | 责任主体模糊，协同单位不标注 |
| When | 时间节点、阶段划分 | 只有"将""计划"，没有具体时间 |
| Where | 范围、区域、场景 | 试行范围不清晰 |
| How | 怎么落地、路径是什么 | 理念多、操作路径少 |
| How much | 投入多少、产出多少 | 缺预算、缺量化指标 |

## 使用方式

审材料时，从本质追问出发，挑最关键的2-3个问号追问。写材料时，Step 1确认需求阶段逐项扫一遍。

## 触发

- 向上汇报材料 → 重点查 Why/How much（推动什么决策、花多少钱）
- 对外宣传材料 → 重点查 What/Who（核心信息、受众画像）
- 内部简报 → 重点查 When/Where（时间节点、覆盖范围）
- 政策解读 → 重点查 Why/How（为什么出台、怎么落地）
- 演讲发言 → 重点查 What/Who（一句话记忆点、听众是谁）
