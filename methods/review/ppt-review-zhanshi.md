# PPT与演讲实战心法

- **适用**：审材料（任何PPT文件，自动匹配）+ 写材料（PPT/演讲稿）
- **优先级**：核心
- **触发条件**：审阅或撰写PPT/pptx格式文件时自动加载。根据PPT内容判断场景，匹配对应审阅重点。
- **来源**：陈丰伟「终端老兵」IMA知识库

## 核心理念

先定场景，再定内容；先定目标，再定表达。PPT会做，话更要会讲。

## 审阅规则

### 1. 场景判断（先确认）

| 场景 | 目的 | 审阅重点 |
|------|------|---------|
| 内部业务 | 高效传递信息、达成共识 | 结论在前、数据在后、动作明确 |
| 产业链合作 | 展现价值与共赢 | 合作价值→自身优势→落地路径 |
| 对外宣传 | 塑造形象、传递价值 | 信息严谨、口径统一、价值鲜明 |

### 2. 内容为王（7条检查）

| # | 检查点 | 怎么审 |
|---|--------|--------|
| 1 | 一页一个核心观点 | 是否每页都能一句话说清？ |
| 2 | 逻辑清晰 | 总分总/问题→分析→方案/时间线，有无结构？ |
| 3 | 数据支撑 | 有数字还是只有形容词？"大幅增长"不如"同比增20%" |
| 4 | 案例有画面 | 有没有让听众代入的具体场景？ |
| 5 | 开场抓人 | 故事/提问/观点/悬念？还是无聊的"今天给大家汇报"？ |
| 6 | 结尾有记忆点 | 总结回顾/呼吁行动/展望/金句？还是"以上就是我的汇报"？ |
| 7 | 避免5个误区 | PPT写成文档？无结论先讲过程？只讲成绩不讲问题？数据多无判断？没练过？ |

### 3. 三分写七分讲

- PPT用关键词+数据图表，不堆字
- 演讲补充细节、故事、判断
- 同一页PPT讲得好坏，结果完全不同

### 4. 演讲前检查清单

- 目标：要推动什么结果？
- 对象：关键听众关心什么？
- 版本：最终稿、数据、口径统一？
- 节奏：每部分多长时间？哪里停顿？
- 设备：投屏、翻页器、字体兼容？
- 开场结尾：第一句和最后一句练熟

## 管理者常见5个误区

1. PPT写成文档（一页塞满字）
2. 没有结论先讲过程
3. 只讲成绩不讲问题
4. 数据很多但没有判断
5. 把现场当第一次完整表达
