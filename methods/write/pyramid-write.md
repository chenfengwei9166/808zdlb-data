# 金字塔写作法

- **适用**：写材料（报告/汇报/简报/解读），结构搭建阶段
- **优先级**：核心（写材料默认加载）
- **触发条件**：用途=写材料

## 核心规则

1. **结论先行**：开篇第一句给出核心判断/结论，不做铺垫
2. **以上统下**：上层观点必须有下层论据支撑，下层必须回答上层疑问
3. **归类分组**：论据按MECE原则分组（相互独立、完全穷尽）
4. **逻辑递进**：每组内部按时间/结构/重要性排序
5. **预演审阅**：写完后用"30秒电梯测试"——30秒内能否说清核心观点

## 结构模板

```
结论（一句话核心判断）
├── 论据A（支持结论的关键事实）
│   ├── 数据1
│   └── 数据2
├── 论据B（另一个支撑维度）
│   └── ...
└── 建议/下一步（由结论自然导出）
```

## 去AI味要点

- 不用"首先...其次...最后..."的机械分层，改用"核心判断是...，支撑这个判断有三点..."
- 结论句要具体、可检验，不写"具有重要意义"这种空话
