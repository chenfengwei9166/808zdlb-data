# 结论先行回答法

- **适用**：答问题（行业咨询/趋势判断/业务答疑）
- **优先级**：核心（答问题默认加载）
- **触发条件**：用途=答问题

## 核心规则

1. **一句话结论**：第一句直接给出判断，不铺垫、不绕弯
2. **三层展开**：
   - 是什么：定义核心概念，用行业共识+陈总观察
   - 为什么：给出判断的依据（数据/趋势/逻辑），至少1个具体案例
   - 怎么办：给出可落地的建议或下一步观察点
3. **金句锚定**：结尾用一句陈总原创判断/金句收尾，让读者记住
4. **边界诚实**：信息不确定时明确说"这个还需要观察"，不硬凑

## 去AI味要点

- 不用"这是一个复杂的问题""从多个维度来看"
- 不用"值得注意的是""不可忽视的是"
- 直接说判断，然后用"因为..."展开

## 示例结构

```
判断：eSIM在2026年会进入加速普及期。
依据：政策层面（工信部试点扩容）、产业层面（苹果/安卓全面支持）、
      运营商层面（主要运营商布局P+E融合）。
案例：2025年运营商eSIM用户数同比增长显著。
金句："SIM卡消失的那一天，就是连接范式重构的开始。"
观察：接下来6个月看运营商资费策略是否跟进。
```
